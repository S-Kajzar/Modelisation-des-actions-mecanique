Projeter une force dans les quatre quadrants

  1. Repère l'axe de l'angle α : horizontal (x ou x') ou vertical (y ou y') ?
  2. Choisis la fonction : sur l'axe de l'angle, la projection est le côté adjacent → F × cos α ; sur l'autre axe, c'est le côté opposé → F × sin α.
  3. Choisis le signe d'après le sens de la flèche : vers la droite Fx > 0, vers la gauche Fx < 0 ; vers le haut Fy > 0, vers le bas Fy < 0.
  4. Signes par quadrant (Fx ; Fy) : quadrant 1 (+ ; +), quadrant 2 (− ; +), quadrant 3 (− ; −), quadrant 4 (+ ; −).
  5. Vérifie : Fx² + Fy² = F², et la plus grande coordonnée est sur l'axe dont la force est la plus proche.

Valeurs tirées au hasard : intensités et angles changent à chaque chargement. Tirage n° ; pour refaire exactement le même sujet, garde le lien de ce tirage. Pour un nouveau sujet : nouveau tirage.

Les unités sont notées : la valeur vaut la moitié des points, l'unité l'autre moitié. Les expressions littérales s'écrivent avec F et α, par exemple -F*sin(α) ; toute écriture équivalente est acceptée.
